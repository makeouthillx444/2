# 🚀 Привет! Мы команда [RR]!

Мы — группа разработчиков, объединённых общей целью: создать приложение **«Трекер привычек»** — удобный инструмент для формирования полезных привычек, контроля ежедневного выполнения и отслеживания личного прогресса.

---

## 📌 Наш проект

Трекер привычек позволяет пользователю:

- ✅ Создавать привычки с названием и описанием;
- 📅 Настраивать периодичность выполнения: ежедневно или по дням недели;
- ⏰ Устанавливать желаемое время выполнения привычек;
- 📝 Отмечать выполнение или пропуск привычек;
- 🔥 Отслеживать текущие и лучшие серии успехов («стрики»);
- 📊 Просматривать статистику выполнения привычек за месяц;
- 🔔 Настраивать напоминания о выполнении привычек;
- 💾 Сохранять профиль и историю отметок;
- 🗂️ Архивировать или удалять привычки.
