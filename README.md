# 🚀 Привет! Мы команда [RR]!
Мы группа разработчиков, объединенных общей целью: создать приложение «Планировщик задач» — удобный инструмент для управления задачами, сроками и приоритетами.
***
## Наш проект
Планировщик задач позволяет пользователю:
- создавать задачи с дедлайнами;
- расставлять приоритеты (высокий/средний/низкий);
- отслеживать прогресс выполнения по категориям;
- получать напоминания о приближающихся сроках;
- сохранять историю выполненных дел.
***
